# List of adapters so far that are manufactured and tested

### AllInOneAdapter

<img width="1723" height="1443" alt="image" src="https://github.com/user-attachments/assets/3cdd57b8-b546-4682-a5b7-9a9e6c3180ab" />
This adapter have:<br>
* 40 pin (this is double side contacts) so some panels will need to reverse it (due to opposite pins but works)<br>
* 34 pin (this is double side contacts) so some panels will need to reverse it (due to opposite pins but works)<br>
* 33 pin (bottom side contacts) as didn't find any reverse panels but if do in future can be updated to support it <br>


### AllInOneAdapter-39pin
<img width="1723" height="1443" alt="image" src="https://github.com/user-attachments/assets/df82f85f-461a-4c61-983b-5aebc20f57fa" />
This adapter have 3 39pin connectors for different models but different style panels could be connected (check schematic)<br>
* ED133UT2<br>
* ED060SC4<br>
* ET107QG1 (U2 on PCB is not populated (for backlight)<br>
